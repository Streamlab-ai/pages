Phase D — Build Enrollment Templates

Build the reusable templates first.

This is the one-time setup John/Ruth completes before Manny uses the OS. Based on the LSVT support answer: create templates inside Assign Training using Assignment Type → Create New Template.

BUILD 01Create Core Program Template
＋
Log in as Super User.
Open menu → Content → 309 Assign Training.
Click + New Assignment.
Find Assignment Type dropdown and select Create New Template. Do not select Courses or From Template.
Assignment Name: T3DU — Core Program Enrollment.
Click + Add Courses and select all confirmed core courses in learning order.
Leave Locations, Users, Due Date, and Notifications blank. Templates store what to assign, not who/when.
Click ASSIGN TRAINING. In template mode, this saves the template.
Go to Templates tab and verify T3DU — Core Program Enrollment exists.
BUILD 02Create Welcome + Orientation Template
＋
Go to Content → 309 Assign Training → + New Assignment.
Assignment Type → Create New Template.
Assignment Name: T3DU — Welcome + Orientation.
Add only INTRO-01, INTRO-02, INTRO-03, FOUND-01.
Leave Locations, Users, Due Date, Notifications blank.
Click ASSIGN TRAINING to save.
Confirm it appears in Templates tab.
BUILD 03End-to-End Test
＋
Create test Location: TEST — DO NOT USE.
Create test user using your own email.
Go to 309 Assign Training → + New Assignment.
Assignment Type → From Template.
Select T3DU — Core Program Enrollment.
Select test Location and test user.
Set due date 7 days from today.
Click ASSIGN TRAINING.
Verify enrollment email arrives and courses appear in learner dashboard.
If email does not arrive, check due date first, then user status, then Location.
Manny Manual

Cohort onboarding SOP.

Follow this exact order for every new T3DU cohort.

PHASE 1Pre-onboarding intake
＋
Get cohort name, example: Forensics — June 2026.
Get start date and expected program duration.
Get learner CSV: First Name, Last Name, Email, optional Team.
Get client POC name and email.
Confirm whether Teams are needed: Executives, Employees, Managers.
Open Milestone Calculator and generate the schedule before assigning training.
PHASE 2Create Location
＋
Log into LightSpeed VT as Super User.
Go to 103 Location Management.
Click Create Location or Add Location.
System: select Think 3D University.
Location Name: use approved cohort name.
Set Active = Yes if shown.
Save and confirm Location appears in the list.
Use Location for cohort/client separation. Do not use Teams as the main cohort container.
PHASE 3Create Teams if needed
＋
Open the new Location.
Open Teams / Manage Teams.
Click Create Team.
Create only approved teams, example: Executives, Employees.
Save each team.
Teams are optional filters inside a Location. They do not replace Locations.
PHASE 4Import users
＋
Go to Manage Users or User Import.
Upload learner CSV.
Map First Name, Last Name, Email.
Assign all users to the correct Location.
Assign Teams if supported by import; otherwise assign manually after import.
Verify users appear under the cohort Location.
PHASE 5Assign training
＋
Go to Content → 309 Assign Training.
Click + New Assignment.
Assignment Type: select From Template.
Template: T3DU — Core Program Enrollment.
Location: select the cohort Location.
Users: select Teams or Select Users.
Set Start Date and Due Date from the Milestone Calculator.
Review notification preview.
Click ASSIGN TRAINING.
PHASE 6Verify launch
＋
Search for one learner.
Confirm correct Location.
Confirm correct courses assigned.
Confirm enrollment email received.
Confirm assignment appears on learner dashboard.

End-of-life flow

CLOSEOUTCompleted learner
＋
Confirm completion status.
Confirm certificate issued or manually resolve blocker.
Confirm final feedback survey submitted if required.
Keep user record for historical reporting.
CLOSEOUTDropped or inactive learner
＋
Do not delete user.
Mark inactive only if approved by Think3D admin rules.
Keep user tied to the cohort Location for reporting history.
Document reason if known.
CLOSEOUTCompleted cohort
＋
Pull final Watchdog report.
Send final client POC summary.
Rename or tag Location as completed if supported, example: Forensics — June 2026 — Completed.
Do not delete Location.
